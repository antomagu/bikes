# 🚲 Montreal Bikes - Bike-Sharing Analysis 

 

## 🎯 Project Overview 

-Exploratory data analysis of Montreal's bike-sharing system using Python to identify usage patterns, peak demand periods, and seasonal trends for operational optimization. 

## Industry Focus 

-Public Transportation 

## Description 

-The project addresses different metrics of the public bicycle system of the city of Montreal, Quebec, Canada, with relevant information that helps us improve the service and optimize station operations. 

## Objective 

-To analyze and create visualizations representing data from the months of June, July, and August 2019. Key metrics include member vs non-member usage patterns, trip duration analysis, station performance, and seasonal trends. 

## 📊 Dataset 

-Source: Kaggle - Montreal Bixi Bike-Sharing Data 

-Records: 2,400,000+ trips analyzed 

-Period: Summer 2019 (June-August) 

-Variables: Start/End stations, trip duration, user type (member/non-member), timestamps 

-Link: View Dataset on Kaggle 

## 🛠️ Technologies Used 

-Python: Pandas, NumPy for data manipulation 

-Visualization: Matplotlib, Seaborn for charts and graphs 

-Analysis Type: Exploratory Data Analysis (EDA) 

-Full Code: View on Kaggle 

## 🔍 Key Findings 

-Member Usage: 2,462,394 trips (79.9% of total) were by members 

-Non-Member Usage: 619,446 trips (20.1% of total) were by non-members 

-Day Patterns: Members show consistent weekday usage (commute pattern) 

-Trip Duration: Members have shorter, more efficient trips vs non-members 

-Top Performing Stations: Stations 6307, 7062, 6734, 6742 (avg 6,932 seconds) 

-Underperforming Stations: Stations 7041, 6133, 6132, 6131, 7026 (avg 303 seconds) 

-Trip Duration Range: From 303 seconds (5 min) to 6,932 seconds (115 min) average 

 

## 💼 Business Impact & Applications 

### Operational Insights 

-**Station Performance**: Identified underperforming stations (avg 303 sec trips) and high-performing stations (avg 6,932 sec trips) for resource optimization 

-**Membership Strategy**: 80% member usage demonstrates strong subscription model success 

-**Capacity Planning**: Trip duration patterns inform bike redistribution schedules 

### Strategic Recommendations 

-Focus marketing efforts on converting 20% non-member users to membership 

-Optimize bike inventory at high-duration stations (6307, 7062, 6734, 6742) 

-Investigate short-duration stations for potential station relocation or service improvements 

-Analyze seasonal patterns for optimal maintenance scheduling during low-demand periods
